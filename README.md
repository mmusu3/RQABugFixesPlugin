# RQA Bug Fixes

This is a plugin for [Torch](https://torchapi.com/) that originally contained a few code patches that fixed various bugs within Space Engineers. After the SE 206 update, two of the bugs were fixed in the game and have now been removed from this plugin.  
The remaining fixes include:  
* Fix for battery blocks draining too much charge after being unconcealed when using the Torch Concealment plugin.

Fixes for more bugs may be added in the future.  

[Here](https://torchapi.com/plugins/view/7144DF6D-1B90-4574-AB40-0C15006CD05F) is the plugin page on the Torch website.
